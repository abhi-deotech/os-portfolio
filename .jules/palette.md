## 2026-05-22 - Palette's Accessibility Policy
**Learning:** All interactive elements in Lumina OS (Taskbar icons, Launcher items, Window controls) must use semantic `<button>` elements with explicit `type="button"`, `aria-label`, and `title` attributes to support keyboard navigation and screen readers.
**Action:** Always use `<button type="button">` for interactive elements and provide descriptive labels.
